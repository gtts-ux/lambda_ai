# lambda 2.4

English conversation model continued from the owner's own lambda 2.2. The owner
selected the release name **lambda 2.4**; the private working name was never a
public model choice. No additional training was performed for this release.

- Parameters: **15,350,401** (lambda 2.2: 11,808,385; approximately 30% more).
- Architecture: 8-layer causal Transformer, width 384, 6 heads, learned pointer-generator.
- Format: v4; context: 512 tokens; inference: CPU float32.
- Requires app **0.5.1**, which supports checksum-verified model downloads up to 64 MiB.
- Selected update: **7000/8000**, total inherited/continuation step **31650**.
- Training set: **150,000** unique synthetic examples,
  approximately 4.97 times the previous set. It includes
  **37,467** topic-switching examples; sampling gives
  that category 40% of training draws.
- All network parameters were trainable. Two new residual blocks initially preserved
  the 2.2 function. The original model/tokenizer were trained from random weights.
  No external pretrained weights, calculator answers, canned replies, retrieval answer
  substitution or topic-based model switching are used during chat.

The curriculum includes names/ages followed by unrelated questions, later explicit
recall, corrections and recovery from faulty earlier assistant text. A small
training-only regularizer discourages inappropriate pointer use on unrelated answers.
Inference still generates every reply from the same neural network.

## Measured results

Each previous assistant message was generated by the evaluated model. Histories
were not filled with ideal assistant answers. Development cases were reused for
checkpoint selection; they are not an unbiased test of general capability.

| Task | 2.2 development | 2.4 development | 2.4 held-out, greedy | 2.4 held-out, default sampling |
| --- | --- | --- | --- | --- |
| Topic switching | 0/24 | 23/24 | 21/24 | 21/24 |
| Memory | 0/8 | 8/8 | 8/8 | 8/8 |
| Arithmetic | 4/8 | 6/8 | 6/8 | 6/8 |
| Chat | 7/8 | 8/8 | 8/8 | 8/8 |

Identity intrusion on topic-switch cases: **24/24 for 2.2 development**, **0/24
for selected 2.4 development**, and **0/24 for both 2.4 held-out decoding runs**.
This checks complete identity values and a few identity-related phrases; it does
not detect every possible irrelevant mention and is not a universal guarantee.

Held-out identities/combinations were excluded from this continuation's training
examples. Task templates and instruction vocabulary overlap. These small synthetic
sets do not measure broad intelligence. Decoding: temperature 0.4, top-k 1 or 8,
80-token output limit, fixed seeds. The terminal defaults to 120 output tokens.
See [raw results and generated histories](lambda-2.4-benchmark.json).

## Limitations and local chats

Recorded failures include `What is 6 + 10?` after a topic change returning `17.`,
and standalone `What is 12 / 3?` returning `6.`. Arithmetic remains unreliable;
unfamiliar prompts/names can still fail, and longer
conversations may drift or repeat. Saved local transcripts can exceed the 512-token
model window; only recent exchanges are supplied. Saving chats does not train weights.
The local-chat UI and shared 1,000,000-token / 10-hour allowance are retained.

## Install

On app 0.5.x, run `/update`, then restart Lambda to load app 0.5.1 or newer. Run
`/update` again if necessary, then `/model use lambda-2.4`.
App 0.5.0 may reject the larger model catalog before its application-update stage
succeeds; after restarting the upgraded app, refresh the models again.

From a terminal:

```bash
lambda update
# Restart the running app after its application upgrade.
lambda update
lambda model use lambda-2.4
```

Earlier models remain selectable. Previously saved chats retain their own chosen
model; select lambda 2.4 inside a chat to switch that conversation.
