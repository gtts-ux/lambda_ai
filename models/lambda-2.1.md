# lambda 2.1

Experimental English conversation model, published at the owner's explicit request
although the earlier automatic quality gates were not met. This release does not
claim broad superiority over lambda 1.6.

- Parameters: 11,808,385.
- Context: 512 tokens, including recent conversation turns.
- Architecture: causal Transformer with a learned pointer-generator output layer.
- App requirement: >= 0.4.0.
- Selected checkpoint: conversation_pilot, 1000 additional updates, total step 23250.
- Origin: the owner's own model and tokenizer, originally trained from random weights.
  No external pretrained weights. Training code, teacher, datasets and optimizer are not shipped.

Selection used the same 56 development cases for five preserved best candidates,
maximizing mean math/chat/memory accuracy while retaining the lambda 1.6 arithmetic
regression score. See [selection results](lambda-2.1-selection.json). These cases
were reused during development and are not an unbiased estimate of general ability.

## Selected checkpoint's separate test results

Greedy generation (top-k 1, temperature 0.4), up to 64 tokens per reply. Earlier
assistant turns were generated by the model. Exact output is required for copying;
other tasks use strict normalized matching, which can reject valid paraphrases.

- math: 15/24.
- math_familiar: 13/16.
- chat: 6/8.
- memory: 6/16.
- copy: 2/24.
- memory_probe: 0/8.

See [raw answers and lambda 1.6 baseline](lambda-2.1-benchmark.json).
The small synthetic test is distinct from the selection cases; its results were
already inspected before the owner's publication request. It is not a new blind test.

The model can repeat fragments, confuse facts or arithmetic, and fail to recall
names and numbers. Earlier stronger automatic publication thresholds remain marked
as failed. This owner-requested experimental release does not change those results.

## Conversation context

Recent completed exchanges are supplied to the same neural model for every question.
There are no calculator answers, canned replies, retrieval answers or topic-based
model switches. The learned pointer distribution is part of the network.

Old exchanges are dropped when the context is full. `/new`, model reload and app
exit clear the context. `/save` exports a conversation but does not teach the model
or provide persistent memory. Included context counts toward the existing allowance.
The default model and 1,000,000-token / 10-hour allowance are unchanged.
